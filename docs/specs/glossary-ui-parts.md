# 画面パーツ用語集

## 目的

`markdown-concat-viewer-vs-code` の Webview UI で使う名称を統一し、仕様書・実装・レビュー時の呼称揺れを防ぐ。

## 用語一覧

- レイアウト全体
  - 定義: Webview の 2 カラム構成全体。
  - 実装識別子: `layout`
- 本文ペイン
  - 定義: 連結された Markdown 本文を表示する左ペイン。
  - 実装識別子: `content`
- TOC ペイン
  - 定義: 見出し一覧と編集導線を表示する右ペイン。
  - 実装識別子: `toc`
- ファイルセクション
  - 定義: 1 Markdown ファイル分の折りたたみ可能な表示ブロック。
  - 実装識別子: `details.file-section`
- ファイルヘッダー
  - 定義: ファイルセクション上部の開閉ヘッダー。
  - 実装識別子: `summary.file-summary`
- ファイルタイトル
  - 定義: ファイルヘッダー内のファイル名表示。
  - 実装識別子: `file-title`
- ファイルパス
  - 定義: ファイルヘッダー内の相対パス表示。
  - 実装識別子: `file-path`
- ファイル本文
  - 定義: 各ファイルのレンダリング済み本文領域。
  - 実装識別子: `file-body.markdown-body`
- TOC グループ行
  - 定義: TOC 上でファイル名見出しと編集ボタンを並べる行。
  - 実装識別子: `group-row`
- TOC グループタイトル
  - 定義: TOC 側のファイル名ラベル。
  - 実装識別子: `group-title`
- TOC 編集ボタン
  - 定義: 対象 Markdown を編集タブで開くボタン。
  - 実装識別子: `toc-edit-button`
- TOC 項目
  - 定義: 見出しリンク 1 件。
  - 実装識別子: `toc a[data-anchor]`
- 見出しアンカー
  - 定義: 本文見出しに付与する遷移先 ID。
  - 実装識別子: `cmv-{fileIndex}-{seq}-{slug}`

## 運用ルール

- 仕様書で新しい UI 要素を追加する場合は、この用語集へ先に追記する。
- 実装クラス名や data 属性を変更した場合は、この用語集と関連仕様を同時更新する。
